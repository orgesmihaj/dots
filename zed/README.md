# zed

Zed settings and keybindings. The keymap is a port of the
[vscode](../vscode/README.md) package on top of Zed's VS Code base keymap, so
both editors feel the same: ⌘K chords for editing and debugging, ⌘G chords
for git, and ⌘K W for splits like Ghostty and vim.

Modus Operandi (light) and Catppuccin Mocha (dark) follow macOS, like the
terminal. The theme and icon extensions install themselves on first launch.
Change the keybindings in both packages so they stay in sync.

Type `keymap zed` in the shell to see the keybindings.
